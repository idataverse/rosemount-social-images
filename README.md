# rosemount-social-images

Public image hosting for Gallery Rosemount (Rosemount International) social media cards.

Finished 1080×1440 JPEGs are uploaded here and scheduled in Buffer using the raw GitHub URL, the same method as [avenleigh-social-images](https://github.com/idataverse/avenleigh-social-images).

Do not use this repository for anything except approved social images.
